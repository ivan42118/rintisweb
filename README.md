# RintisWeb · Jasa Pembuatan Website

<img src="assets/logo/png/rintisweb-logo-tagline-warna-2000.png" alt="RintisWeb, jasa pembuatan website" width="360">

Situs jualan jasa pembuatan website: **toko online**, **company profile**, dan **landing page**, lengkap dengan lima website contoh dan kalkulator potongan marketplace. Semuanya statis (HTML/CSS/JS biasa), tanpa server atau database, dan ringan di HP Android kelas menengah.

- **Pengaturan (nomor WA, harga, promo, daftar contoh):** [config.js](config.js)
- **Template untuk pesanan klien:** [templates/](templates/README.md)
- **File logo siap pakai:** [assets/logo/](assets/logo/README.md)

## Website contoh

| Contoh | Paket | Folder |
|---|---|---|
| Kanaya Wear (toko baju) | Toko Online | `contoh/kanaya-wear/` |
| Langkah Footwear (toko sepatu) | Toko Online | `contoh/langkah-footwear/` |
| Batik Sekar Jagad (batik Cirebon) | Toko Online | `contoh/batik-sekar-jagad/` |
| Sekar Wedding (wedding organizer) | Company Profile | `contoh/sekar-wedding/` |
| Kopi Tepas (kafe) | Landing Page | `contoh/kopi-tepas/` |

Semua usaha di website contoh adalah fiktif. Foto produk dari [Unsplash](https://unsplash.com) (lisensi Unsplash, boleh dipakai untuk usaha); daftar fotonya ada di [contoh/KREDIT-FOTO.md](contoh/KREDIT-FOTO.md).

## Jalankan di komputer

```powershell
python -m http.server 5510
```

Lalu buka http://localhost:5510.
